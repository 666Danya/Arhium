Основная фанатская энциклопедия оригинальной трилогии S.T.A.L.K.E.R.: «Тень Чернобыля», «Чистое Небо», «Зов Припяти».

**Статус:** подготовка основного репозитория. Проверенная HTML-сборка ещё не загружена, GitHub Pages для него ещё нужно включить. Пожалуйста, не путайте эту страницу с опубликованной бетой.

- Тестовая версия: [archium-beta](https://github.com/666Danya/archium-beta)
- Правила подготовки релизов: [docs/RELEASE_PROCESS.md](docs/RELEASE_PROCESS.md)
- Базовая локальная проверка HTML: [tools/check_release.py](tools/check_release.py)

Для выпуска основной версии: проверка HTML и тест на iPhone → отдельная ветка релиза → перенос проверенных файлов в `main` → настройка GitHub Pages.
