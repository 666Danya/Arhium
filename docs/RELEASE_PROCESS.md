# ARCHIUM — процесс выпуска основной версии

Этот репозиторий предназначен для **основной** энциклопедии «АРХИУМ».
Экспериментальная версия находится отдельно: [archium-beta](https://github.com/666Danya/archium-beta).

## Структура на старте

- `index.html` — главная HTML-сборка; добавляем только после проверки.
- `tools/check_release.py` — базовая проверка сборки перед публикацией.
- `docs/RELEASE_PROCESS.md` — порядок выпуска.

Пока сайт — один крупный HTML-файл. Разделение на `assets/css`, `assets/js`, `assets/images` и `data` делаем **постепенно** с проверкой на iPhone, не переписывая всё разом.

## Контроль перед публикацией

1. Сохранить неизменённую копию предыдущего `index.html`.
2. Проверить номер версии и заголовок: `python tools/check_release.py index.html --version 6.51` (подставить реальную версию).
3. Проверить переключатели ТЧ / ЧН / ЗП, досье группировок, аномалии, артефакты, персонажей, оружие, броню, мутантов, локации, карту и настройки.
4. Проверить сезонные фоны и включение/выключение эффектов.
5. Проверить браузер на компьютере, затем реальный iPhone в Safari.
6. Публиковать на `main` только после успешной проверки. Для изменений использовать ветки `feature/...` или `release/...`.
7. Не переносить в основную версию модуль «КОНТУР»; не изменять `archium-beta` в ходе основных релизов.

## GitHub Pages

После загрузки проверенного `index.html` включить в репозитории:
**Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.**

Ожидаемый адрес для текущего имени репозитория: `https://666danya.github.io/Arhium/`.
Публикация не включается одним только наличием этой инструкции.
