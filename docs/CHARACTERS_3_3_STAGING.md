# АРХИУМ 3.3 — единый реестр персонажей

## Готово

- `data/characters-archium-3.3.json`: 234 уникальных личных дела оригинальной трилогии S.T.A.L.K.E.R.
- Стрелок/Меченый и Бродяга/Страйдер приведены к единым личным делам.
- Одинаковые позывные разных людей не объединяются без подтверждения.
- Полная локальная HTML-сборка: `ARCHIUM_3.3_CHARACTERS_UNIFIED.html` (подготовлена отдельно и ещё не опубликована в репозитории).

## Перед выпуском основного сайта

1. Добавить полную проверенную HTML-сборку как `index.html` на релизную ветку: в `main` пока нет этого файла.
2. Сверить связи и досье персонажей, открыть разделы «Аномалии», «Локации» и «Группировки».
3. Проверить прокрутку, фото, фильтры и переходы на настоящем iPhone.
4. Только после успешной проверки переносить обновление в `main` и отдельно включать GitHub Pages.

Не изменять `archium-beta`, не переносить модуль «КОНТУР».
